# 🚀 SkillBuddy

SkillBuddy is an AI-powered peer learning and collaboration platform that connects students based on their skills, learning goals, interests, and availability. It helps learners find study partners, mentors, teammates, and communities while providing personalized AI recommendations.

---

## ✨ Features

- 🔐 Secure Authentication with Clerk
- 👤 User Profiles with Skills & Learning Goals
- 📄 Resume Upload & Management
- 🤖 AI-Powered Skill Recommendations (Google Gemini)
- 🔍 Smart User Discovery
- 🤝 Connection Requests
- 💬 Real-Time Chat
- 👥 Communities
- 👨‍💻 Team Collaboration
- 🏆 Leaderboard & Gamification
- 🔔 Notifications
- 🌙 Light/Dark Theme Support
- 📱 Responsive UI

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Dinesh022006/SkillBuddy.git
```

Go into the project:

```bash
cd SkillBuddy
```

Install dependencies:

```bash
npm install
```

Create a `.env.local` file and configure:

```env
DATABASE_URL=
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=
CLERK_SECRET_KEY=
UPLOADTHING_TOKEN=
GEMINI_API_KEY=
```

Run the development server:

```bash
npm run dev
```

Visit:

```
http://localhost:3000
```
